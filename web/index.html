What is LoveSpouse Gateway?

Protocol Translation

Translates Lovense BLE protocol to control MuSE, LoveSpouse, and Leten toys seamlessly.

Wide Compatibility

Works with popular platforms like XToys.app and buttplug.io for maximum flexibility.

Multi-Device Support

Connect and control multiple devices simultaneously with a single ESP32 gateway.

Features

Graphical Interface

Built-in display support for CYD (Cheap Yellow Display) devices with intuitive controls.

  • Real-time device status
  • Connection monitoring
  • Touch controls

Supported Hardware

Compatible with multiple ESP32 variants for flexible deployment options.

ESP32 ESP32-S3 CYD
